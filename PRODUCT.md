# Product

## Register

product

## Users

A developer learning GitHub Actions and AWS deployment on a shared EC2 host.

## Product Purpose

Show the running frontend version prominently, with a trustworthy environment label and release identity. Two independently deployed copies represent staging and production for learning.

## Brand Personality

Clear, precise, calm. Use familiar shadcn/ui components and a restrained developer-tool layout.

## Anti-references

No marketing hero, decorative dashboard cards, fake release history, or simulated deployment actions.

## Design Principles

- The version is the primary content.
- Environment identity is always visible and never selected as a cosmetic mode.
- Display real release data; unknown state must not imply a successful deployment.
- Keep the same build usable in both environments.

## Accessibility & Inclusion

Readable text, visible keyboard focus, named icon controls, reduced-motion support, responsive layout, and environment names alongside status colors.
